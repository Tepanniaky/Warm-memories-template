# Música

Coloque aqui a música que deseja usar na página.

Por exemplo:

```text
assets/audio/music.mp3
```

Depois, em `js/config.js`, altere:

```js
music: {
  enabled: true,
  file: "assets/audio/music.mp3",
  volume: 0.25
}
```

> Evite publicar músicas protegidas por direitos autorais no repositório sem permissão.
